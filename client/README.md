# Campus Management Platform — Client (React Native / Expo)

This directory houses the mobile frontend for the Campus Management Platform, designed to run cross-platform on iOS, Android, and Web using **Expo**.

## Planned Screens (Member C ownership)

- **Authentication**: Sign-up (UC-13), Log in / Log out (UC-01)
- **Profile**: Student details, active club memberships and positions (UC-02)
- **Calendar**:
  - Default view (Campus, own Section, joined Club events) (UC-03)
  - Section switcher & read-only preview (UC-04)
  - Filtering by date range, club, and section (FR-8)
- **Event Management**:
  - Create/edit club event (UC-06)
  - Create/edit section event (UC-07)
  - Request campus event approval (UC-14)
  - My Requests status tracker
- **Admin Screens**:
  - Approval queue for campus events (UC-15)
  - Club & position management (UC-10, UC-11)
  - Student registry management (UC-09)
